# Optimization of Electric Vehicle Charging Infrastructure in Istanbul

A Mixed-Integer Linear Programming (MILP) based optimization system for 
EV charging infrastructure planning in Istanbul. The system decides which 
candidate stations to open and how much capacity to add to existing stations,
minimizing accessibility cost, unmet demand, investment cost, and overload penalty.

## Setup

### 1. Clone the repository
```bash
git clone https://github.com/itu-itis24-kerimi23/Optimization-of-Electric-Vehicle-Charging-Infrastructure-in-Istanbul.git
cd Optimization-of-Electric-Vehicle-Charging-Infrastructure-in-Istanbul
```

### 2. Create virtual environment
```bash
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Mac/Linux
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Add raw data files
Place the following files in `data/raw/`:
- `sarj_istasyonlari.geojson` — IBB EV charging stations
- `sarj_istasyon_soket.csv` — IBB socket data
- `ispark_parking.csv` — ISPARK parking lots
- `nufus_bilgileri.xlsx` — District population data
- `ibb_ev_yillik.csv` — IBB yearly EV registration data

### 5. Run the data pipeline
```bash
python -c "import sys; sys.path.append('src'); from data_processing import run_pipeline; run_pipeline()"
python src/distance_calculator.py
```

### 6. (Optional) Run sensitivity analysis
```bash
python src/sensitivity_analysis.py
```

### 7. Launch the web application
```bash
streamlit run app.py
```

## Model Parameters

| Parameter | Value | Description |
|---|---|---|
| α | 1.0 | Accessibility cost weight |
| β | 20.0 | Unmet demand penalty weight |
| γ | 1.0 | Investment cost weight |
| λ | 50.0 | Overload penalty weight |
| ρ | 0.20 | EV to charging demand conversion factor |
| Budget | 50M TL | Total investment budget |
| D_MAX | 20 km | Maximum assignment distance |

## Key Findings

- **MILP vs Greedy:** MILP reduces unmet demand by ~50.4% compared to the greedy heuristic
- **Sensitivity Analysis:** Critical threshold at λ=10
- **Strategy:** Expanding existing stations is preferred over opening new ones (~44x cost difference)

## Known Limitations

- ρ (conversion factor) is estimated from EPDK data, not directly calibrated
- Cost parameters (G, F, H) are literature-based estimates
- Logistic growth curve fitted on only 5 data points (2020-2024)
- K_MAX_EXISTING set uniformly for all stations
